# 雾锁逸园（1940npc）

一座被雾封锁的 1940 年代上海法租界洋馆——一场充满克苏鲁气息的侦探悬案。

受邀参加赵公馆春宴裁缝沙龙的名流宾客中，林婉清在舞会上离奇失踪，公馆大门被密令封锁，所有宾客暂成疑犯。调查员追查失踪者、诡异的裁缝铺与墙后暗藏的真相。

## 内容

- **世界设定（worldbook）**：16 条（公馆、雾、宾客、NPC、线索、真相）
- **类型变量**：4 个进度追踪器
- **预建调查员**：4 名（沈默、顾雅琴、陆远风、白露）
- **配图**：7 张（封面 + 3 场景 + 2 NPC + 物品）
- **KP 技能**：雾锁洋馆
- **规则系统**：coc7（直接使用内置 CoC）
