# 深水城的仲夏节盛典（midsummer-festival-of-waterdeep）

深水城仲夏节前夜，集市中央展台的一颗“狮鹫蛋”不翼而飞，玩家必须在节日狂欢背后追回它，并决定它的最终归宿。

第零回合：PC们刚刚在深水城港口广场的“仲夏集市”上落脚，或是因为来到城市过节，或是因为办事经过。卫兵格伦·哨兵正在展台前急得团团转——一颗装饰华丽的“蛋”被人偷走了。他拜托PC们帮忙找回失物，承诺报酬50金币。线索将把他们引向漫游塔、鱼市场背后的旧下水道，以及半身小偷皮普的秘密巢穴。
