# 灰岩港的潮汐（tide-of-grayrock）

海雾弥漫的缅因渔村中，一尊从海底打捞出的石偶像正把村民拖向深潜者与血月之门。

调查员们在黄昏进入灰岩港，车停在蓝蟹旅店门外。镇上钟楼停留在三点三十三分；海风裹着盐粒。艾米琳·弗罗斯特三天前寄来的求救信仍在口袋里，她却已失踪。离血月还有三天。调查员需要弄清潮汐之眼的秘密、在邪教仪式前救出艾米琳，并决定是否毁掉那件来自海底的展品。
