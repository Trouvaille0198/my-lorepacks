# 剑湾拾光集——贝壳湾的失窃信物（sword-coast-keepsakes）

在和平的剑湾海滨小镇贝壳湾，帮拾光节找回被一只迷路幼格里芬偷走的五件珍贵信物，收获一段温暖明亮的收集与回忆之旅。

你们沿着剑湾商路旅行，在拾光节前夜抵达了贝壳湾。节庆主理人玛拉婆婆的五件珍贵信物一夜失窃，镇民众说纷纭；北方红海崖的潮汐洞窟里，藏着一个小小的、闪着金光的秘密。你们可以自由行动：询问镇民、检查展台、追踪足迹，或先在客栈「海风与铃铛」好好吃一顿再说。

## 内容

- **规则系统**：D&D 5e
- **世界设定（worldbook）**：26 条
- **类型变量**：4 个进度追踪器
- **预建调查员**：6 名（顾晚棠、黎木、佩妮·齿轮、苏尔雅、罗格·铁锅、米粒·海风）
- **物品**：20 件（13 件通用 + 7 件剧情）
- **配图**：28 张（1 封面 + 4 场景 + 6 NPC + 11 线索 + 6 调查员）
- **KP 技能**：温暖旅途与收藏冒险
