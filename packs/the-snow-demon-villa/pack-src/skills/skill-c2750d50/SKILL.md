# 日式怪谈暴风雪山庄

这个技能是为“暴风雪山庄”“近代日本”“日式怪谈”这一特定玩法服务的。当模组把一群调查员困在一座与世隔绝的山庄，让他们面对一系列无法用科学解释的灵异事件时，使用本技能。你要做的不只是主持一次CoC团，而是把日式怪谈的“毛骨悚然”和封闭环境的“无处可逃”变成游戏的核心体验。

**核心基调**

一切要带着“不祥的静寂”。使用日本近代的山村、旅馆或别馆作为舞台，强调老旧的木造建筑、潮湿的榻榻米、摇晃的烛影、远处的雨声。恐怖不是来自突然跳出的怪物，而是来自违反日常常识的细节：不该出现的脚步声、佛龛里转动的眼睛、镜子中迟了一瞬的倒影。不要直接描述“妖怪”，只描述现象和它们引起的生理反应——后颈发凉、汗毛竖起、耳内嗡鸣。

**封闭的暴风雪山庄**

明确告诉玩家山庄的地理隔绝：唯一的吊桥被冲断，电话线被风雪压断，山路因崩塌无法通行。精确记录时间和天气，用天黑、雨雪、断电来制造压力。山庄的内部结构要画成地图，让玩家知道哪些房间、哪些门可以锁、哪里可能藏人。山庄里的人（包括NPC和其他调查员）都不能随意离开，这就逼着玩家在内部寻找答案。

**事件结构**

把一个核心谜团（如一场多年前的灭门、冤死的亡魂、受诅咒的仪式）拆成3到5个“怪异事件”依次触发。每起事件都满足：表面异常 → 调查线索 → 触碰禁忌 → 获得碎片。事件之间给玩家喘息时间，让他们整理线索、互相讨论、处理人际关系。切忌连续惊吓，那会让玩家变得麻木。

**调查与机制**

自由度上遵循CoC，但要有侧重：
- 侦查、聆听、图书馆、历史、民俗学是最常用的技能，细致描述线索，别让玩家因一次失败就卡住。
- 民俗学最容易被忽略，却是日式怪谈的关键。给懂民俗的调查员机会，通过传说、地名、生活习惯解释现象。
- 对灵异现象不要给出科学解释，代之以“民间说法”或“老人的告诫”，让玩家自己拼凑真相。
- SAN损失设计成“细水长流”：看到恐怖异像损失少一些，但知道真相后一次性承受巨大冲击。

**人际与角色**

6名调查员应有各自的背景、秘密和来山庄的目的。用秘密制造张力：有人知道旧事，有人身怀使命，有人只是被无辜卷入。NPC要像活人，有自己的日常行动和隐私。利用信息不对称——有的角色看到了别人没看到的东西，有的角色在深夜独自行动——让他们在互相猜疑中判断该信任谁。

**怪谈的呈现**

运用日式怪谈的经典套路：
- 禁忌规则：如“夜里不要应门外人的呼唤”“不要把脸浸入水缸”“不要打开那扇西侧的纸门”。提前埋下规条，让玩家在无意中触发，再揭示后果。
- 视觉暗示：用余光、影子和反光表现灵异，避免正面出现。越不清晰，越让玩家恐惧。
- 声音：远方的钟声、纸门的沙沙声、女人的啜泣、木板深处的敲击。
- 物品：一粒干涸的血迹、一串褪色的念珠、一张旧照片，每件都带出处和异样。

**结局设计**

不要指望靠武力解决。真正的解法往往是民俗性的：找出怨念的源头，完成未了的心愿，或者举行一场仪式。让玩家通过调查确认仪式所需的物品和步骤，并在慌乱中执行。结局可以是净化，也可以是更深的绝望，但要忠于怪谈的宿命感。

**主持提醒**

- 保持怪谈的含蓄，不要过度渲染血腥与恶心，除非事前与玩家确认过。
- 涉及暴力、死亡、精神创伤的内容，提前确认玩家接受度。
- 将节奏控制在“安静—异常—恐怖—平静”的循环里。
- 始终记得：这是日式怪谈，不是战斗团。紧张来自理智的流失和人际的猜疑，而非单纯的HP消耗。
