# 雪鬼山荘（the-snow-demon-villa）

暴风雪封山的近代日本山间旅馆中，调查员们被迫面对一场跨越百年的雪鬼诅咒。

大正十五年冬，众人被邀请到藏王深山中的北原山莊参加赏雪会。暴风雪袭来，山路断绝。翌日，山莊主人北原龙三离奇失踪，随后佣人与客人接连惨死。调查员们必须在被雪封的孤绝之馆中揭开雪鬼传说的真相，并决定自己的命运。
