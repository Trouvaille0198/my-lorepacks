# 雨林祭坛（jungle-altar）

在1840年代英属马来亚内陆雨林深处，一支清代广东押运队撞上非人祭祀的古老祭坛，必须在丧失理智前查明真相。

暴雨将押运队困在槟榔屿内陆雨林，货船上的文物『深海之星』失踪，向导坚持绕祭坛而行，而祭坛的守卫开始夜袭营地。
