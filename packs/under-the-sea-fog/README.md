# 海雾之下：川崎临海工业区调查记录（under-the-sea-fog）

1968 年的川崎临海工业区，工人接连发疯失踪，调查员在浓雾和旧战遗迹中触及古老禁忌。

1968 年冬，川崎市临海工业区。多家工厂传出工人发疯消失的传闻，官方以集体癔症搪塞。调查员因不同缘由聚集于此，有人受失踪者家属之托，有人为新闻猛料而来，有人察觉到异常气息。此刻，昭和化学工厂的夜间换班刚刚开始，海雾正从港口涌向厂房。
