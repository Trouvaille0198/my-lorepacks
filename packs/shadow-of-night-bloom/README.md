# 夜来香之影（shadow-of-night-bloom）

1920 年代的上海，舞厅名伶接连失踪，繁华租界地下潜伏着潮汐教团的深海献祭阴谋。

调查员们因不同缘由聚集在霞飞路的夜来香舞厅——有人受亲友之托寻找失踪的舞女白玫瑰，有人受巡捕房密邀探查人口失踪案，也有人只是被一封匿名信引到此处。舞厅内爵士乐喧闹，红男绿女沉醉，但空气中隐约弥漫着海腥味，墙角的阴影似乎比往日更深。
