# 蛇渡诡祭（serpentferry）

清末光绪年间，一群飘零南洋的中国人卷入英属马来亚橡胶园深处的血腥祭典，被迫直面被封印的异星造物与殖民者同谋的黑暗交换。

六名调查员因各自机缘聚集于丹戎巴莱镇的华人会馆。近来橡胶园接连有华工失踪，会馆管事陈阿贵私下恳求他们探查。镇上雾汽不散，码头黑影出没，土著祭司脸上刺着蛇鳞，英国种植园主则摆出笑脸。他们在第九位失踪者名单交到手上时，意识到这不是简单的私贩劳工案。

## 内容

- **世界设定（worldbook）**：20 条
- **类型变量**：4 个进度追踪器
- **预建调查员**：6 名（林文远、刘阿福、苏月娘、陈少卿、赵展鹏、慧清）
- **物品**：16 件（8 件通用 + 8 件剧情）
- **配图**：12 张（1 封面 + 2 场景 + 2 NPC + 1 物品 + 6 调查员）
- **KP 技能**：南洋苍凉诡谲
